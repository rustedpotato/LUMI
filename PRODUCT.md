# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Knowledge workers, students, developers, and creators who need a calm, high-clarity daily task planner that effortlessly translates messy thoughts into scheduled, actionable work.

## Product Purpose
LUMI is an intelligent task planning sanctuary. It offloads mental clutter by taking unstructured natural language descriptions and breaking them into clear, prioritized, deadline-aware tasks backed by SQLite persistence, intuitive calendar scheduling, project categorization, and focused review workflows.

## Positioning
Unlike heavyweight enterprise tools (Jira, Linear) or rigid, barebones checklists, LUMI delivers zero-friction cognitive offloading: you dump whatever is on your mind in plain English, and LUMI immediately structures it into a workable day plan without tedious form-filling.

## Operating Context
- Morning focus routines: braindumping todos and organizing priorities for the day.
- Mid-day triage: reviewing upcoming deadlines and rescheduling or completing deliverables.
- Project tracking: organizing cross-functional tasks into clear contextual streams.
- Quiet, low-friction desktop and mobile browser sessions.

## Capabilities and Constraints
- AI task parsing via OpenRouter (extracting task names, priorities: High/Medium/Low, explicit deadlines, and calendar dates)
- Manual quick-add with project assignments and reminder timestamps
- Local persistent storage via SQLite (`planora.db`)
- Multi-view navigation: Dashboard & AI Planner, Calendar Day View, Projects Breakdown, Kanban-style Task Board, and Scheduled Reminders
- Built with Python and Streamlit, augmented by custom semantic CSS design system

## Brand Commitments
- Name: LUMI (✦ LUMI)
- Character: Serene, sharp, focused, purposeful. Tactile, premium editorial feel without sterile gray monotony or cheap AI-purple gradient slop.

## Evidence on Hand
- Streamlit application (`app.py`), styling (`style.css`), database (`planora.db`), config (`.streamlit/config.toml`).

## Product Principles
1. **Zero-friction offloading:** Entering work should be as effortless as thinking out loud.
2. **Calm clarity:** High contrast, legible typography, tight groups, generous breathing room. No sensory overload.
3. **Dependable truth:** Changes persist instantly and state is clear at a glance.
